### Count like this counts the same for any reasonable box; round 6's two fixes

Count like this took its template from everything in the box, at distances that grew with the box, so one troffer on Baker EL1.01 counted anywhere from 0 to 24. The box now only says where: the symbol's own black ink in it is grouped at a fixed gap, specks, grey grid, lettering drawn as paths and clipped neighbours are left out, and the symbol's tight bounds become the template. A box holding two symbols asks which. Measured over 30 boxes per symbol (`lib/takeoff/realplan/countBox.eval.ts`): the first keyed instance of R1, OS, E2, X1 and CD-1 now counts its right number from all 15 boxes; three second instances still vary, because ink drawn touching them becomes part of the template.
