### Set type touches only the group it was pressed on

Chrome on Baker: Set type S6B on the 114 ft 7-3/8" group also filed two other
7-3/8" groups (17 ft tagged S6A, 20 ft tagged S8B) under S6B, and after Undo the
heading and its legend height stayed. Set type wrote the group's thickness onto
the type's item, "remembered for the job", and detection then matched every
group that thick to it. It writes no thickness now, so only the runs of the
group pressed move; and Clear type (Set type's Undo) takes the thickness off a
typed item it leaves empty, so an item an earlier build left behind stops
claiming groups.
