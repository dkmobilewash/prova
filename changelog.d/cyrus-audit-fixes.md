### Eight fixes from today's four audit reports — Ask's first lie, homeowner copy, WH-347's silent hours, four click-stamped dates, phone/copy smalls, tour drift, a tool's missing gate, and company-scoping belt-and-braces (Cyrus)
`cyrus/audit-fixes`

1. **Ask's first suggested chip lied to a brand-new company.** "What's overdue and who do I chase first?" routed to `receivables`, which answered "Every invoice raised has been paid in full" on an account that had raised none — the same falsehood `ReceivablesPanel` was already fixed for. `handlers.ts` now branches on invoices-raised count. `findJob` dead-ended the same way on chip 4 ("Log today's field report"): asked "Which job?", then `No job matches "…"` with nowhere to go on an empty account — it now says so and points at `/jobs/new`. Added a "What should I set up first?" chip, which routes to the one tool built for this (`getting_started`) and every other chip assumes something already exists.
2. **Six first-hour pages, plus the pipeline example, talked to a "homeowner."** The buyer is a union commercial sub who has never had one. Reworded `/rfis`, `/punch-lists`, `/photos`, `/messages`, `/contacts`, `/bids` and the `/pipeline` example row to GC/architect/developer language — same sentences, trade-neutral audience.
3. **WH-347 silently dropped hours outside the query window, and a mid-week rate change corrupted a line instead of splitting it.** A schedule that takes effect mid-week now gets its own printed line per worker/craft, ordered by effective date, instead of one line printing one rate against gross computed at two. Hours whose date misses the seven-day grid are now counted into a new blocking field (`hoursOutsideWeek`) instead of vanishing from a filing.
4. **Four evidence dates were stamped at the click, not entered on the viewer's calendar day.** Retainage release (blank-field default), change-order submit/approve/reject/void, RFI `markRfiSent`, and RFI `answerRfi`'s blank-field default all now use `viewerToday()` instead of the server's UTC day — a release or a send after ~5pm US time was landing on tomorrow's date on a document a GC has already seen. The job page's retainage row also now renders pre-migration rows (raw click instants) as an instant in the viewer's zone rather than misreading them through `formatCalendarDate`.
5. **Phone and copy smalls.** `AskLauncher`'s panel was `absolute right-0` off its ~44px button — at 375px the 343px panel hung off-screen; now viewport-fixed like `HelpButton`. `/schedule` and `/lien-deadlines` rows/grids now stack below `sm` instead of forcing a name + status pill + GC name onto one 295px line. `/team` now renders the actual sign-up URL with a copy button instead of promising a link it never showed. `/intake`'s dropzone sentence now matches its header — filename read, not file contents. "License bond" → "Licence bond" on `/settings`, matching the page's own voice everywhere else. Softened owner-facing internals: `/messages`' Resend env-var names and `/settings/integrations`' Photo storage store-id diagnostics are now gated behind `company.isProvaOperator` (the same flag already gating `/sales` and `/internal/usage`) with a plain "isn't set up yet" sentence for everyone else; `/backcharges`' "is real work that hasn't been built" standup sentence is now user-facing.
6. **The 3-minute tour, offered only to zero-job accounts, narrated controls a zero-job account can't see.** `jobs-new.ts`'s "press + Add a new GC" step now carries the same hedge every sibling walkthrough has ("With no GCs on your account yet…"). The punch-lists tour stop now carries the same empty-state caveat the page itself shows. The integrations stop no longer instructs "Connect Jobber" unconditionally when it may not be set up on this install. "Billing section" → "Invoices" (the job page's actual heading) on both the full tour and `/cash-flow`'s own walkthrough and empty-state copy — there is no "Billing section."
7. **`team_roster`'s capability gate was `null`.** It reports certifications-on-file and what's missing on them — summarised from `/certifications`, guarded by `MANAGE_FIELD` — but was offered to every signed-in member on the reasoning that `/team` itself is open. Now gated `MANAGE_FIELD`, matching `/certifications` exactly. `tools.test.ts`'s recorded gap is closed rather than carried forward.
8. **Defense-in-depth company scoping on Ask's write paths.** `audit.ts`'s `targetLinks` and six post-write decoration lookups (`billing.ts` payment lookup, `equipment.ts` assignment lookup, `field.ts` ×3 — daily report existence/lookup and delivery lookup, `labor.ts` time-entry lookup) now carry an explicit `companyId`/`job.companyId` clause. Every one of these ids already came off a row the preceding action had proven in-company, so this is belt-and-braces rather than a live breach — it makes the function safe under refactor for a caller that didn't scope its rows first.

Not touched: Diego's lane (payment/retainage deletes, subcontract delete, `sendOutboundEmail` gate, invite flow, webhook signatures, QuickBooks token encryption, spend limiter — filed as #351-353), and `/safety` / `/material-orders` stay hidden pending Cyrus's call.
