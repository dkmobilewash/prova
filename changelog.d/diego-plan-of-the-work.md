### A life-safety plan is never the plan of the work, and a set with nothing to count asks which sheet is (Diego)
`diego/plan-of-the-work`

**Life-safety rule.** Aldrich's A001 LIFE-SAFETY PLAN, a code plan of the whole existing school shaded "no work", was
the only plan the walls run counted on Excell Academy's side of the upload. So once #1237 sets Kurita's sheets aside,
the job would have been priced off existing walls.
- The product already refused LIFE SAFETY, CODE and EGRESS titles. It missed only the hyphenated LIFE-SAFETY, in both
  the sheet-only list and the floor-plan rank. Both are now one character wider.
- Pre-registered and measured on the 100-set sweep: exactly one sheet changes, Aldrich's A001.
- 0 keyed sheets are refused by the change. (Joplin G-101's refusal by the existing CODE word is older, and queued.)

**Nothing to count is a question, never a silent zero** (behind `TAKEOFF_PROJECT_IDENTITY`, with #1237's question).
- **When it asks:** when the run would count no sheet at all, after the which-project question. The whole-set panel
  asks "Which sheet shows the work?" and lists the project's sheets titled as a plan, with thumbnails and none ticked.
- **The answer** is stored in `TakeoffPlan.planOfWorkPages` (migration `20261121030000_add_takeoff_plan_plan_of_work_pages`,
  additive). The named sheets are counted whatever their title says, and never folded into each other.
- **How often:** on the sweep, 4 of 91 named sets have nothing to count (one is held out), plus Aldrich once A001 is
  refused. The Aldrich A111 lift stays held until a training set besides Aldrich shows the shape: the contractor names
  A111 instead.
