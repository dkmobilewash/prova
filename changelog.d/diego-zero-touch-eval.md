### The zero-touch bid accuracy eval: AUTOMATION-PLAN's one number, measured

`zzZeroTouch.eval.ts` opens every keyed set (training and held-out separately), presses nothing, and prices what
reaches the estimate — un-held wall runs after the app's own demolition comparison, marked doors, no windows —
against the key's quantities through one deterministic price table, per set and in total; then the same after the
first ten review answers taken from the key in the shipped review order. It reuses the finder, hold, pairing and
review-order code the app runs, so the number moves exactly when the product does.
