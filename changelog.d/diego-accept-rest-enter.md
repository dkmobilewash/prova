### "On all N groups" keeps its word when the type has no height

In the review queue, "A" gives the picked type to every group on the sheet that
nothing names. When the type had no height it first asked for one, in the height
box — and Enter there accepted only the group on screen, though the button had
said all of them (found on ELEVEN03 A3.2: 15 groups promised, 1 taken). Enter in
the box now finishes the accept that asked: all the groups for "A", with the
height typed or left for later, and the prompt says "on all N". Enter on a single
group still takes only that group.
