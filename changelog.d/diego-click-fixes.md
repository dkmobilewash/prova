### Counts become items, and a Find shows its result

A named count, by hand or with Count like this, now creates or joins a count item, so it reaches the Items list instead of Unassigned, and saving across sheets keeps the panel up to say what was saved. Count like this no longer takes a neighbour's tag for a labelled symbol, and an empty symbol no longer matches the same shape with text across it. A Find opens the results rail, which starts closed on smaller windows. Check: on Baker EL1.01, box an OS sensor beside a troffer and expect 16.

Framed notes and legends no longer come back as rooms, and on a sheet that marks its doors, a door with no mark is not counted. Check: Baker A101 reads 18 doors, none in (E) Dispatch or (E) Training.
