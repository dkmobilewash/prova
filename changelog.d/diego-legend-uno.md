### The legend read extracts the "unless noted otherwise" defaults

- `extractWallLegend` (`wall-legend.2`) asks for each U.N.O. sentence with
  the type it names and records them as `WallLegendRead.uno`, verbatim;
  `readWallLegend` and `legendForPlan` carry the list into the set's legend
  and the stored proposal, where the detection already reads it as each
  type's default sentence. A floor plan whose partition sheet says "all
  interior drywall partitions are type A" types its untagged drywall footage
  A on the real path, not only from a hand key. `wallLegendReadFrom` is the
  parser, tested without a call.
