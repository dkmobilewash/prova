### Answer key: a just-split wall can be typed straight away

A split leaves both halves undecided, and the type picker (and 1–9) only appeared on accepted
walls; pressing A first moved focus on to the next wall, so the number typed that one. Round 25
on Baker A101 fell back to clicking the type buttons. Now any undecided wall (unreviewed or
unsure) shows the picker, and giving it a type accepts it as a wall in the same step. A wall
marked "not a wall" still gets no picker.
