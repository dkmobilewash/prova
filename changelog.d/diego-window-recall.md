### A sheet tagged by its window schedule's marks counts its interior windows, when they have glass in the wall

Training windows found 139 of 182 (43 missed, all Topeka). By cause: frame not read 22, counted but 2–4 ft off the mark 15, tag 3–10 ft away 4, a storefront read as one frame 2 — none untagged. Of the 22 unread frames, 20 sit on walls `exteriorWalls` calls interior (a courtyard plan), and an interior window was accepted only when the sheet "tags every window", which knew only W-number tags; Topeka tags A to F, its schedule's marks. The frame finder now uses `windowsByTag`'s own tag vocabulary (`windowTagVocabulary`, one definition): three or more schedule-mark tags mean every window is tagged. On such a sheet — and only there, so W-tagged sheets (Baker, Bunkie) are unchanged — a tagged frame on an interior wall must still have a glass line inside the wall, so a tag beside casework or a counter does not make a window (the gap test rejected 13 of Topeka's real windows and is not applied there). Training: 139 / 43 / 28 → 153 / 29 / 4 (found / missed / false). Held-out, measured once: 82 / 10 / 17 → 87 / 5 / 9. Without the glass check the training gain was larger (168 / 14 / 6) but held-out false rose to 36, so it is not shipped that way. Check: `doorWindowSymbols.test.ts` (glass inside / casework beside, red with the check removed); `windowTags.test.ts` wiring.
